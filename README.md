A program that writes one line under 200 characters that gets you out of work and gets a laugh. It keeps a shortlist of hand-written sick-day excuses, scores each against the judge's own rubric (half-believable first, then freshness, then whether the laugh lands before the last word), and writes the winner to `/output/entry.txt`. The winning line:

> I can't come in today — my back filed for divorce and I'm stuck negotiating custody of my legs.

(A bad back, escalated to a custody battle over the legs.)

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt` (95 characters, one line) and verifies it against the gate (1–199 characters, not only whitespace, single line) before exiting.
